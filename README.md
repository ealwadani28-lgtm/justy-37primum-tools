# th24-primum-tools

A TypeScript-based project with styling support.

## 📋 Project Overview

This repository contains tools and utilities built primarily with **TypeScript**, with some CSS styling and minimal JavaScript support.

## 🛠️ Technology Stack

- **TypeScript**: 97.1% - Primary language for type-safe code
- **CSS**: 2.7% - Styling and presentation
- **JavaScript**: 0.2% - Minimal legacy or configuration support

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher recommended)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/ealwadani28-lgtm/th24-primum-tools.git

# Navigate to the project directory
cd th24-primum-tools

# Install dependencies
npm install
```

### Usage

```bash
# Run the project
npm start

# Build the project
npm run build

# Run tests
npm test
```
